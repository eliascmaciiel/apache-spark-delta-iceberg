# Apache Spark e PySpark

## O que é
Apache Spark é um motor de processamento distribuído para grandes volumes de dados. No projeto, usamos o **PySpark** para escrever código em Python.

## Por que usar em Engenharia de Dados
- Processamento em lote e SQL em larga escala;
- APIs de DataFrame e SQL simples para ETL;
- Ecossistema maduro para integrações com Delta Lake e Iceberg.

## Conceito de DataFrame
DataFrame é uma estrutura tabular com esquema definido e execução otimizada pelo Spark Catalyst.

## Uso com JupyterLab
JupyterLab facilita experimentação, documentação e visualização de evidências no mesmo notebook.

## Relação com Delta e Iceberg
Spark é o mecanismo de execução; Delta e Iceberg são formatos de tabela com recursos de ACID, versionamento e evolução de schema.
