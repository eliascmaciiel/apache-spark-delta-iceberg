# Apache Spark com Delta Lake e Apache Iceberg

Este projeto demonstra, de forma didática, como usar **PySpark** com dois formatos de tabela para Data Lakehouse:

- **Delta Lake**
- **Apache Iceberg**

O objetivo é apresentar um fluxo local, reproduzível em ambiente acadêmico, com exemplos de:

- criação de tabelas;
- `INSERT`, `UPDATE` e `DELETE`;
- leitura analítica com Spark SQL;
- documentação técnica com MkDocs.
